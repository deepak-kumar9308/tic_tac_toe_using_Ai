# 🎮 Tic-Tac-Toe Game in Python

A simple and interactive **Tic-Tac-Toe game built using Python**.
The game allows two players to play against each other on the same computer through the terminal.

## 📌 Features

* 🎮 Two-player gameplay
* ❌ Player 1 uses `X`
* ⭕ Player 2 uses `O`
* 🏆 Automatically detects the winner
* 🤝 Detects a draw
* 🔄 Displays the updated game board after every move
* ⚡ Simple and beginner-friendly Python code

## 🛠️ Technologies Used

* **Python 3**
* **Lists / Arrays**
* **Loops**
* **Conditional Statements**
* **Functions**

## 🎯 How to Play

1. Player 1 starts with `X`.
2. Player 2 uses `O`.
3. The board contains 9 positions.
4. Enter the position number where you want to place your symbol.
5. Players take turns.
6. The first player to get **three symbols in a row** wins.

### Winning Combinations

```text
1 | 2 | 3
---------
4 | 5 | 6
---------
7 | 8 | 9
```

A player wins by completing any row, column, or diagonal.

For example:

```text
X | X | X
---------
O | O | 6
---------
7 | 8 | 9
```

🎉 **Player X wins!**
